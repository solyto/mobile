## Coding standards

This project's coding standards are in `docs/STANDARDS.md`. They are
binding for every change.

- Before writing or changing code, read that file and follow it.
- When reviewing, check the diff against it. A violation in changed code is a
  blocker; cite the rule and the offending file and line.
- Only code the change touches has to comply. Do not bring untouched code in
  line with the standards unless the task asks for it.
- If a task can't be done without breaking a rule, say so instead of breaking it.
