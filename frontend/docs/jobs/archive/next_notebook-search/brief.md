## What

The notebook is missing one crucial function: search. We already have search in libraries. Let's grab the same type of component (visually + shortcuts, etc.) for notebook. Let's search for notes, they're already in the store.
In libraries, it'll just filter the view. In the notebook, we need to do it differently. When you've searched something, extend the search bar to be a larger box that shows entries. When you click one, navigate to that note. Alternatively, you should be able to navigate with keys and enter.
