# Translation guide

How UI strings get into `src/lib/i18n/*.ts`. Binding for every change that
adds or changes a string. The `translator` agent (`docs/agents/translator.md`)
applies this guide; other agents hand translation work to it instead of
translating on the fly.

## Workflow

1. The change adds or edits the string in `en.ts` (the source of truth) and
   the key in `types/translation.ts`. `de.ts` too, if the author is sure of it.
2. The translator agent fills every other locale from the English string,
   following the voice, glossary and rules below.
3. `npm run check` must pass (all locale files have the same keys).
4. New terms that will come up again go into the glossary in the same change.

The owner reviews `en` and `de`. Other locales are machine-translated by this
process; native-speaker feedback (issues, user reports) beats this guide and
goes into the glossary.

## Voice

- Informal, friendly, short. The app talks to one person about their own data.
- Informal address everywhere: `de` du, `fr` tu, `es` tú, `it` tu. Never mix
  within a language. Address the user directly ("Check your connection"), not
  impersonally.
- Write it as a native app in that language would, not as a word-by-word
  translation. Rephrase when the English structure sounds stiff.
- Button and menu labels: verb in the imperative or infinitive as the
  language's apps usually do (`de` "Speichern", `fr` "Enregistrer",
  `es` "Guardar", `it` "Salva"). Keep the form consistent within a language.
- Sentence case for labels unless the language capitalizes nouns (`de`).

## Rules

- **Placeholders** stay exactly as in English: `%s`, `%d`, `{n}` and any other
  `{name}`. Same count, same type, order may change to fit the grammar.
  Never translate or reformat them.
- **Plurals**: keys come in `_singular` / `_plural` pairs; translate both,
  even when the language would phrase the singular differently.
- **Length**: labels (buttons, nav items, tabs, column headers) should be at
  most ~30% longer than the English. If a word does not fit, pick a shorter
  synonym before abbreviating.
- **Punctuation**: follow the language's rules (`fr` a plain space
  before `? ! : ;`, `es` opening `¿ ¡`). Apostrophes stay straight (`'`),
  as in the existing files.
- **Brands and product names** stay untranslated: solyto, Telegram, CalDAV,
  CardDAV, WebDAV, iCal, Markdown.
- Do not touch keys outside the change, even if they look wrong. Report them
  instead (known drift: `docs/backlog/i18n-consistent-voice-and-terms.md`).
