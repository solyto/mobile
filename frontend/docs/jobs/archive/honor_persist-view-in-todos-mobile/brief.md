## What

A user has given this feedback:
If I set the 'view type' in my To Do's, it resets to the default if I switch away to calendar or dashboard and then switch back. The view type should persist after switching back, as a Quality of Life feature.

To my knowledge, the view you selected on the todos page is already persisted. It should already have the functionality to remember the todo view, but it seems to be broken. Find the issue, fix it - both for web, mobile, desktop.
