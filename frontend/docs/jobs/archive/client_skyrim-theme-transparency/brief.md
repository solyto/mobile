## What

We have different themes.
Some themes have transparency (currently exclusively the skyrim theme).
That leads to issues on mobile. On mobile you often have a hamburger menu on secondary navigations. That hamburger menu has a transparent background and can then not be read against the actual bg.
Please fix this. I assume we should add a class to secondary navigations (mobile only) and then set that class for the skyrim theme to not be transparent, but something matching.
